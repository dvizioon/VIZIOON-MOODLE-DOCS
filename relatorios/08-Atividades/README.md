## Criar Assignment (Trabalho)

### Passo a Passo

1. No curso, clique em "Ativar edição"
2. Clique em "Adicionar uma atividade ou recurso"
3. Selecione "Assignment"
4. Configure:

| Campo | Descrição |
|---|---|
| Nome | "Trabalho de Pesquisa" |
| Instruções | "Escreva um artigo sobre..." |
| Data de entrega | 30/11/2025 |
| Tipo de envio | Upload de arquivo |
| Limite de arquivos | 1 |
| Tamanho máximo | 10MB |
| Tipo de nota | Escala ou Valor |

5. Salve

### Tipos de Envio

- Upload de arquivo
- Texto on-line
- Upload de arquivo + Texto
- Sem envio (apenas nota manual)

## Criar Quiz (Prova)

### Passo a Passo

1. "Adicionar uma atividade ou recurso"
2. Selecione "Quiz"
3. Configure:

| Campo | Descrição |
|---|---|
| Nome | "Prova P1" |
| Instruções | "Responda todas as questões" |
| Limite de tempo | 60 minutos |
| Tentativas permitidas | 1 |
| Embaralhar | Sim |
| Comportamento | Feedback adiado |

4. Salve
5. Clique em "Editar prova"
6. Adicione questões do banco

### Configurações Importantes

| Configuração | Opções |
|---|---|
| Limite de tempo | Minutos para completar |
| Tentativas | 1, 2, 3 ou ilimitadas |
| Embaralhar | Questões e/ou respostas |
| Navegação | Livre ou sequencial |
| Revisão | O que mostrar após entregar |

## Criar Forum

### Tipos de Forum

| Tipo | Descrição |
|---|---|
| Padrão | Discussões gerais |
| Perguntas e Respostas | Cada aluno faz uma pergunta |
| Postagem única | Um tópico fixo |
| Fórum de Notícias | Apenas professores postam |

### Criar Forum

1. "Adicionar uma atividade ou recurso"
2. Selecione "Forum"
3. Configure:

| Campo | Descrição |
|---|---|
| Nome | "Discussão: Meio Ambiente" |
| Tipo | Padrão |
| Modo de agrupamento | Grupos visíveis |
| Respostas | Sim |
| Anexos | Sim |
| Avaliação | Escala |

## Criar Recurso

### Upload de Arquivo

1. "Adicionar uma atividade ou recurso"
2. Selecione "File"
3. Faça upload do arquivo
4. Nome: "Apresentação da Aula 1"
5. Salve

### Página Web

1. "Adicionar uma atividade ou recurso"
2. Selecione "Page"
3. Nome: "Conteúdo da Aula 1"
4. Conteúdo: Texto, imagens, links
5. Salve

### Link Externo

1. "Adicionar uma atividade ou recurso"
2. Selecione "URL"
3. Nome: "Artigo complementar"
4. URL: https://exemplo.com/artigo
5. Salve

## Configurações Gerais

### Disponibilidade

| Campo | Descrição |
|---|---|
| Disponível de | Data de início |
| Disponível até | Data de término |
| Ocultar | Não mostrar aos alunos |

### Conclusão de Atividade

| Condição | Descrição |
|---|---|
| Marcação manual | Aluno marca como concluído |
| Visualizar | Conclui ao acessar |
| Enviar | Conclui ao enviar |
| Nota mínima | Conclui ao tirar nota mínima |

### Restrições de Acesso

| Restrição | Descrição |
|---|---|
| Data | Disponível apenas em datas específicas |
| Nota | Requer nota mínima em outra atividade |
| Conclusão | Requer conclusão de outra atividade |
| Grupo | Disponível apenas para grupo específico |

## Boas Práticas

1. **Nome claro** - "Prova P1 - Frações" não "Atividade 1"
2. **Instruções completas** - Explique o que esperado
3. **Datas visíveis** - Defina prazos claros
4. **Feedback** - Sempre inclua feedback
5. **Organização** - Use seções e tópicos
6. **Teste antes** - Verifique se funciona corretamente
