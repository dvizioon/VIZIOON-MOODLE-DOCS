# Competências no Moodle

## O que são Competências?

Competências são habilidades ou conhecimentos que o aluno deve desenvolver. O Moodle permite:
- Vincular competências a atividades
- Rastrear progresso
- Criar planos de aprendizagem
- Gerar relatórios de competências

## Estrutura

```
Planos de Aprendizagem
├── Planos (ex: "Plano de Graduação")
│   ├── Competências
│   │   ├── Competência 1
│   │   └── Competência 2
│   └── Cursos vinculados
```

## Criar Competência

### Passo a Passo

1. Administração do Site > Competências
2. Clique em "Adicionar competência"
3. Preencha:
   - Nome: "Pensamento Crítico"
   - Descrição: "Capacidade de analisar e avaliar..."
   - ID Number: "PC01"
   - Framework: Selecione o framework
   - Categorias: Vincule a categorias
4. Salve

### Configurações

| Campo | Descrição |
|---|---|
| Nome | Nome da competência |
| Descrição | O que mede |
| ID Number | Código único |
| Framework | Framework pai |
| Categorias | Categorias do framework |
| Padrão | Escala padrão |

## Frameworks de Competência

### Criar Framework

1. Administração do Site > Competências > Administrar framework
2. Clique em "Criar novo"
3. Nome: "Competências Profissionais"
4. Selecione a escala
5. Salve

### Adicionar Competências ao Framework

1. No framework, clique em "Adicionar competência"
2. Selecione a competência criada
3. Organize a hierarquia

## Planos de Aprendizagem

### Criar Plano

1. Administração do Site > Planos de aprendizagem
2. Clique em "Criar plano"
3. Nome: "Plano de Gestão"
4. Descrição: "Competências para gestores"
5. Vincule competências
6. Salve

### Vincular a Cursos

1. No plano, aba "Cursos"
2. Adicione os cursos relevantes
3. As competências ficam disponíveis nesses cursos

## Usar em Atividades

### Vincular Competência a Atividade

1. Crie/edite uma atividade
2. Configurações > Competências
3. Adicione as competências relevantes
4. Configure a escala para cada uma

### Avaliar Competência

1. Após o aluno entregar a atividade
2. No relatório de notas, aba "Competências"
3. Avalie cada competência na escala

## Relatórios

### Relatório de Competências

**Caminho:** Curso > Mais > Relatórios > Competências

**O que mostra:**
- Progresso por competência
- Média de avaliação
- Alunos que atingiram o nível esperado

## Escalas para Competências

Use escalas qualitativas:
- "Não atingido, Parcialmente, Atingido"
- "Iniciante, Intermediário, Avançado"
- "Insuficiente, Suficiente, Bom, Excelente"

## Boas Práticas

1. Comece com poucas competências (5-10)
2. Use descrições claras
3. Vincule a atividades relevantes
4. Revise regularmente o progresso
5. Use planos para organizar
