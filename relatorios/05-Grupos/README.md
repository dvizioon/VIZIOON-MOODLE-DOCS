# Grupos no Moodle

## O que são Grupos?

Grupos são subconjuntos de alunos dentro de um curso. Permitem:
- Separar turmas no mesmo curso
- Atividades exclusivas para um grupo
- Fóruns separados por grupo
- Notas separadas por grupo

## Tipos de Agrupamento

| Tipo | Descrição |
|---|---|
| Grupos separados | Cada grupo vê apenas seus membros |
| Grupos visíveis | Todos veem todos, mas estão organizados |
| Grupos mistos | Combinação dos dois |

## Criar Grupos

### Passo a Passo

1. Acesse o curso
2. Mais > Usuários > Grupos
3. Clique em "Criar grupo"
4. Preencha:
   - Nome: "Turma A"
   - Descrição: "Alunos da manhã"
   - Vagas: (opcional)
5. Salve

### Adicionar Alunos ao Grupo

1. Selecione o grupo na lista esquerda
2. Clique em "Adicionar/remove usuários"
3. Selecione os alunos na lista direita
4. Clique em "Adicionar"
5. Salve

## Atribuição de Grupos

### Na Atividade

1. Crie/edite uma atividade
2. Configurações > Grupo
3. Selecione o modo:
   - Grupos separados
   - Grupos visíveis

### No Fórum

1. Crie/edite um fórum
2. Modo de agrupamento: "Grupos separados"
3. Alunos só veem posts do seu grupo

## Grupos Aleatórios

O Moodle pode criar grupos automaticamente:

1. Mais > Usuários > Grupos
2. "Criar grupos aleatórios"
3. Quantidade de grupos ou alunos por grupo
4. Distribuir ou misturar

## Com agrupamento (Groupings)

Agrupamentos são coleções de grupos. Útil para:
- Criar "Turma A - Manhã" e "Turma A - Tarde"
- Cada turma tem seus próprios grupos de atividades

### Criar Agrupamento

1. Mais > Usuários > Agrupamentos
2. "Adicionar agrupamento"
3. Nome: "Turma A - Manhã"
4. Salve
5. Atribua grupos ao agrupamento
