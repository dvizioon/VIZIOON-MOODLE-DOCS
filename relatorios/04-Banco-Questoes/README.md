# Banco de Questões

## Tipos de Questão

| Tipo | Exemplo |
|---|---|
| Múltipla escolha | "Qual é a capital?" |
| V/F | "O Sol gira em torno da Terra" |
| Resposta curta | "Quanto é 2 + 2?" |
| Numérica | "Qual é π?" |
| Dissertação | "Explique o ciclo da água" |
| Correspondência | "Capital → País" |
| Ordem | "Ordene os planetas" |
| Arrastar e soltar | "Complete a frase" |
| Cloze | Várias questões misturadas |
| Descrição | Texto informativo |

## Criar Questão

1. Curso > Mais > Bancos de questões
2. "Criar uma nova questão"
3. Selecione o tipo
4. Preencha: nome, texto, respostas, feedback
5. Salve
